# 卫星整星能源平衡分析——调研续篇（面向真实遥测）


本文是《01_技术调研报告_卫星整星能源分析》的查漏补缺续篇，聚焦于**如何用真实遥测落地整星能源平衡分析**，沉淀本次在 `chdb_3body` 集群上的实测经验，作为后续算法与工具开发的依据。

## 1. 真实遥测环境下的三个关键认知

### 1.1 能量守恒是评估的锚
任何能源平衡评估必须自洽：**发电 = 负载 + 电池净交换 + 分流**。若残差不闭合，说明负载口径、分流估计或损耗未建模，应先修正模型再谈指标。本次框架以此作为必经校验。

### 1.2 "貌似矛盾"的两个电流遥测先统一口径
同一颗星常同时提供「母线电流」与「负载电流」两路遥测（本星 TMD017 / TMD018）。实测表明两者差距大（~350 W vs ~180 W），原因在于母线电流含电池充电需求。**必须先通过数据判断哪一路是真实负载，再做平衡计算**，否则会得出错误的充电/分流比例。

### 1.3 突发式采样限制 SOC 连续积分
真实遥测往往为"脉冲窗口"采集，非连续，纯库仑(SOC积分)会因采样缺口累积漂移而失真。**用"电压锚定 SOC"对突发数据更诚实**，放电/浮充状态都能即时反映。

## 2. 真实数据实测到的能源系统特征

- **发电极充裕**：功率裕度约 200%，太阳阵大幅过设计，光照占比约 93%。
- **储能深放电是真实关注点**：地影期电池 DoD 最坏 5% 达 53%，SOC 中位降至 47%。
- **母线稳定度 4.6%**：略超 3% 目标，与地影/高负载切换相关。
- 太阳阵总电流与各帆板电流之和相关性 1.0，帆板结构一致。

## 3. 方法学要点（可复用经验）

| 主题 | 推荐做法 | 本次实证 |
|------|---------|---------|
| 负载口径 | 多电流遥测先判断，TMD018 作主、TMD017 交叉 | 180 W vs 350 W |
| 能量闭合 | 残差应≈0，作为模型自洽判据 | 日照残差≈0 ✓ |
| 储能 SOC | 电压锚定为主，库仑计数为辅 | SOC 逐样本电压映射 |
| 分流模型 | 电池满充(SOC≥95%)后再计分流 | 分流≈600 W 级富余 |
| 抗毛刺 | p5/p95/中位数评分，全局极值单列 | DoD p95=53% 合理 |
| 深放电风险 | DoD、SOC p5、母线低点联合监控 | 暴露 53% DoD |

## 4. 后续研究方向（结合 008 总结报告）

1. **连续遥测接入**：突破突发采样限制，按轨道分段补全，支持逐轨 SOC 递推。
2. **电池电流遥测/库仑交叉校验**：校准电压→SOC 曲线。
3. **深放电识别**：建立"地影+高负载"叠加下的 DoD 预测，纳入任务规划。
4. **电池寿命/容量衰降**：长期跟踪 DoD 频次与容量变化（对应研究方案阶段三）。
5. **负载结构精细化**：按分系统聚合，定位高负载来源与调度空间。
