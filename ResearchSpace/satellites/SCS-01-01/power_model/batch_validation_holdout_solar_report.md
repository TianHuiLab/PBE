# 三体01星太阳阵发电功率历史拟合

## 1. 目标口径

采用用户确认的方案B：

```text
P_solar_array_proxy = P_load + P_charge_est
P_load = TMD016 × TMD018
P_charge_est = max(TMD016×TMD017 - TMD016×TMD018, 0)
```

这是01星暂定目标代理量。`P_charge_est`由母线测点差额推断，不是独立电池充电测量；太阳阵电压测点损坏也不参与本模型。

## 2. 模型

- 类型：`polynomial`
- 阶数：`3`
- 系数（按阳照片段开始后小时数的幂次升序）：`[373.273535038, 500.648782134, -2377.944746383, 1866.497702967]`
- 时间支撑：`[0.0, 0.983333] h`；超出后按训练边界截断。
- 阴影片段：固定`0.0 W`。

## 3. 训练与验证

- 有效阳照分钟：`11,461`
- 阳照连续片段：`2,837`
- 历史阴影分钟：`5,531`
- 时间范围：`2025-12-26T00:12:00` 至 `2026-11-05T09:45:00`
- 整日排除：`['2025-12-27', '2025-12-28', '2025-12-29', '2025-12-30', '2025-12-31', '2026-02-22', '2026-03-01', '2026-03-05', '2026-05-01', '2026-05-02', '2026-05-23', '2026-06-01', '2026-06-02', '2026-06-29', '2026-07-11', '2026-07-13']`
- 排除行数：`3,982`
- 目标功率 p05 / p50 / p95 / p99：`194.766` / `383.684` / `612.504` / `703.872` W
- 分组验证恒定模型RMSE：`135.894669` W
- 各阶候选RMSE：`{"1": 130.440487, "2": 129.506095, "3": 128.152885}`
- 选中模型RMSE：`128.152885` W

验证按完整阳照片段分组，避免同一片段相邻分钟同时进入训练和留出集。

## 4. 预测输入

`prediction.phase_segments`必须连续、有序、无重叠，并完整覆盖`[time,end)`。`phase`可取`sun/eclipse`或“阳照/阴影”等别名。阳照片段按片段内经历小时评价多项式，阴照片段功率为0 W。

## 5. 证据边界

- 目标功率是用户指定方案B的条件代理量，不是独立太阳阵功率测量。
- `P_charge_est`仍受 `TMD017` 测点边界影响，不能支持物理闭合结论。
- 模型未显式包含温度、太阳入射角、S3R工作点、阵列老化或姿态变化。
- 多项式超出历史时长范围会截断，不向未知长光照窗口自由外推。
