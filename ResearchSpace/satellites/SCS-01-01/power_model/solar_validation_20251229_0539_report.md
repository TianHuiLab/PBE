# 三体01星太阳阵模型验证：2025-12-29 05:39–06:10

## 1. 验证设计

- 验证窗口：`2025-12-29 05:39:00–06:10:00`，31个连续分钟，全为阳照。
- 选择原因：该段从明确阳照开始，时间连续，且终点存在`TMD019`遥测，可直接用V-SOC曲线比较目标SOC。
- 防泄漏：从太阳阵模型训练集中排除`2025-12-29`全天。
- 留出训练集：12,156个有效阳照分钟、2,994个阳照片段；仍选择3阶多项式，分组CV RMSE为130.64 W。
- 任务计划：历史验证没有未来任务单，因此不配置单机任务；未来负载按起始遥测背景负载保持不变。
- 观测基准：太阳阵功率按方案B代理量`P_load+P_charge_est`，目标SOC按终点`TMD019`和项目V-SOC曲线计算。
- 能量比较：31个`[t_i,t_i+1)`区间采用两端遥测平均功率，与60秒积分步长对齐。

| 指标 | 结果 |
|---|---:|
| 初始SOC | 86.1905% |

| 观测目标SOC | 91.4815% |

| 预测减观测 | **-0.4506个百分点** |
| 相对初始SOC误差 | 0.523% |
| 相对观测SOC变化误差 | 8.52% |
| 预测剩余 | 59.170 Ah / 1.657 kWh |
| 观测剩余 | 59.463 Ah / 1.665 kWh |
| 剩余Ah偏差 | -0.293 Ah |
| 剩余能量偏差 | -0.00820 kWh |

因此，本次闭环预测的目标SOC偏低约**0.45个百分点**。

## 3. 太阳阵功率与负载误差

| 指标 | 结果 |
|---|---:|
| 预测太阳阵能量 | 0.189008 kWh |
| 观测太阳阵代理能量 | 0.222416 kWh |
| 太阳阵能量偏差 | -0.033408 kWh（-15.02%） |
| 太阳阵功率平均偏差 | -64.66 W |
| 太阳阵功率MAE | 70.21 W |
| 太阳阵功率RMSE | 86.68 W |
| 预测负载能量 | 0.098188 kWh |
| 观测负载能量 | 0.092957 kWh |
| 负载能量偏差 | +0.005231 kWh（+5.63%） |
| 起始恒定背景负载 | 190.04 W |
| 观测平均负载 | 178.63 W |
| 观测负载CV | 26.4% |

太阳阵模型明显低估本段功率；恒定负载假设则高估整段负载能量。两者对SOC误差的方向相同，但负载路径差异使部分误差发生抵消。

## 4. 误差分解

| 太阳能输入 | 负载输入 | 目标SOC | SOC偏差 |
|---|---|---:|---:|
| 模型预测 | 起始背景负载恒定 | 91.0309% | **-0.4506 pp** |
| 模型预测 | 实际逐分钟负载 | 91.3097% | -0.1718 pp |
| 实际方案B代理 | 起始背景负载恒定 | 92.8114% | +1.3299 pp |
| 实际方案B代理 | 实际逐分钟负载 | 93.0902% | +1.6087 pp |

结论：

1. 端到端SOC误差0.45个百分点看起来较小，但其中包含太阳阵低估与负载假设误差的部分抵消。
2. 把负载替换为真实路径后，太阳阵模型仍使目标SOC偏低0.17个百分点。
3. 即使太阳能和负载都换成历史实测代理，电池/电压映射记账仍有约1.61个百分点的正偏差，说明后续应优先校准电池充电滞回、效率和V-SOC方向差异。
4. 单段验证不能作为全期精度结论；下一步应批量抽取不同光照时长、不同负载水平和不同季节的留出片段。

## 5. 证据边界

- 观测太阳阵功率不是独立测量，仍采用用户暂定的`P_load+P_charge_est`。
- `P_charge_est`由TMD016/TMD017/TMD018测点差额推断。
- 观测SOC由蓄电池电压映射，充电滞回、温度、倍率和老化未建模。
- 本窗口没有未来任务计划，负载按起始背景值恒定处理。
- 本次结果用于判断模型现阶段可用性，不代表飞行级精度。
