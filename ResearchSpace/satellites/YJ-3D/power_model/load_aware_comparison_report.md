# 云尖3D星负载感知BCR模型留出测试

## 模型

最终采用：

```text
P_BCR_out ≈ intercept
             + beta_time × elapsed_hours
             + beta_load × predicted_total_load_W
```

任务计划先通过单机模型生成未来总负载；BCR模型再以该预测负载为输入。任务单机功率和活动单机数也作为候选特征测试，但闭环结果不稳定，未进入最终模型。

## 测试设计

- 10个JJA/SON、短/中/长光照、低/中/高负载片段。
- 全部验证日期从单机模型和太阳阵模型中排除。
- 历史任务计划从稳定active/idle状态变化提取。
- 同一任务计划下比较纯时间一阶和负载感知模型。
- 观测目标SOC为初始V-SOC锚点+独立TMEA006电流积分，属于条件参考。

## 总体结果

| 指标 | 纯时间一阶 | 时间一阶+未来负载 |
|---|---:|---:|
| 目标SOC MAE pp | 0.856 | 0.462 |
| 目标SOC p95 pp | 2.838 | 1.531 |
| 剩余容量MAE Ah | 0.323 | 0.174 |
| 剩余容量p95 Ah | 1.070 | 0.577 |
| 太阳能量MAE % | 17.74 | 15.42 |
| 太阳能量偏差 % | -5.39 | -13.22 |
| 负载能量MAE % | 8.12 | 8.12 |

## 特征消融

| 特征组合 | 目标SOC MAE pp | 剩余Ah MAE | 太阳能量MAE% |
|---|---:|---:|---:|
| 时间一阶 | 0.856 | 0.323 | 17.74 |
| 时间+负载（采用） | 0.462 | 0.174 | 15.42 |
| 时间+负载+任务功率 | 0.472 | 0.178 | 15.81 |
| 时间+负载+活动数 | 0.443 | 0.167 | 18.59 |
| 四项全加 | 1.070 | 0.403 | 25.14 |

活动单机数的SOC MAE略低，但太阳能量MAE恶化到18.59%，且依赖预测状态分布稳定性；因此最终采用负载特征。

## 结论

- 未来负载是最有效且稳定的新增特征。
- 任务状态通过任务计划转换为预测负载后仍参与闭环，但不直接作为不稳定的BCR模型特征。
- 07-28片段太阳能量误差从时间一阶的57.79%降到10.65%。
- 09-11 00:59片段仍有约-62.85%太阳能量误差，后续需要轨道/姿态和更完整的负载状态。
