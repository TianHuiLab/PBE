# 云尖3D星 A/B 双支路物理单机建模

> [`新一代通用平台单机方案及硬件使用说明20220315-14点.doc`](../../../../Data/0010-云尖3D星/新一代通用平台单机方案及硬件使用说明20220315-14点.doc)
> 图3、图4、第33页和第76页。

## 1. 拓扑结论

- 图3为 `PLA` 上板配电，图4为 `PLB` 下板配电；
- 两块板的 DCDC 上游独立，对应 `PL_Vn` 的配电开关输出并联到同一外部负载；
- 同名 `PLA_n/PLB_n` 是同一物理单机的双供电支路，不是两台独立单机；
- 设备计数只算一次，支路电流和功率相加，电压取公共值或有效较大值；
- 任一支路缺测时，物理单机总功率保持缺测，不把缺测支路当作0 W。

批准契约见 [`ab_topology.json`](ab_topology.json)，包含22对PL支路。
原始54个支路模型继续保留用于审计。

## 2. 物理模型

22对PL A/B加10个加热主路后形成32个物理预测对象：

```text
P_plN = P_plN_A + P_plN_B
```

训练目标在物理单机级重新生成；9个验证日期不进入留出模型训练。
实时ClickHouse快照会先展开A/B支路测点，再按同一规则合并。

## 3. 同一冻结窗口对比

| A/B聚合口径 | 负载能量MAE | 太阳阵能量MAE | 目标SOC MAE |
|---|---:|---:|---:|
| 原始支路模型（聚合前） | 5.64% | 13.28% | 0.151 pp |
| 全部A/B求和（采用） | **3.88%** | **11.35%** | **0.149 pp** |
| 求和但飞轮只取A | 4.03% | 11.41% | 0.149 pp |
| 二次配电择一、一次配电求和 | 6.45% | 11.79% | 0.149 pp |
| 全部A/B取最大 | 12.77% | 13.87% | 0.149 pp |

10窗口未过QC的原始诊断口径：

| 指标 | 聚合前 | 全部求和后 |
|---|---:|---:|
| 负载能量MAE | 6.42% | **4.16%** |
| 太阳阵能量MAE | 15.04% | **13.12%** |
| 目标SOC MAE | 0.473 pp | **0.472 pp** |

因此正式采用全部A/B求和。它不是“去掉一个重复测点”，而是把同一物理负载
的实际供电路径合并；只有物理设备目录去重。

## 4. 边界

- 目标SOC仍有4/7个主窗口处于触顶状态，MAE不能代表全部工况；
- 背景负载仍在窗口起点保持恒定，是当前长窗口误差的重要来源；
- 电池充放电效率暂取1.0，绝对SOC仍需多窗口独立锚点；
- 物理功率仍是分钟电压×电流代理，不是独立硬件能耗表。
