# 云尖3D星MPPT输入功率测点核查

## 结论

现有资料中**没有找到8路PV支路对应的输入电流遥测，也没有找到直接下行的MPPT输入功率测点**。

该结论已完成交叉确认：

- 遥测大表两个BCR页均为可见普通页，无隐藏行、隐藏列、隐藏页签或批注；
- 数据库3,499列中BCR参数严格为`TMBA001–091`和`TMBB001–091`，没有额外PV/MPPT命名列；
- 硬件说明确认板内应监测每路输入、输出电压和电流；
- 之江平台资源分配表不包含BCR/MPPT遥测；
- 全工作簿检索没有`PV*_In_Current`、`MPPT`或直接输入功率字段。

当前可用的是：

- `TMEA007`：全部太阳阵支路总电流；
- 8路PV输入电压；
- 8路BCR输出电压；
- 8路BCR输出电流。

硬件说明确认BCR内部具备逐路输入/输出电压、电流监测能力，但遥测大表没有把8路PV输入电流作为独立下行参数列出。这是遥测接口缺口，不是数学上可以忽略的测量。

## 资料核查结果

### 遥测大表

- `0303-BCR_A`和`0304-BCR_B`分别只有4路PV输入电压。
- 每个通道有输出电压和输出电流。
- 全工作簿搜索`MPPT`、`In_Current`、`输入电流`、`PV_IN`等关键词，没有找到PV输入电流参数。
- 数据库`chdb_3D.yc_history`共有3,499列；BCR相关只有`TMBA001–091`和`TMBB001–091`，没有额外汇入的PV输入电流列。

### 硬件说明

硬件说明明确：

- BCR使用`LT8490/LT8491`实现最大功率点跟踪（MPPT）；
- 最多支持8路充电通道；
- 板内EPS处理器对每路输入、输出电压和电流进行监测；
- 故障模式章节还列出“输入电流采样芯片失效导致输入电流遥测异常”。

因此可以判断：**输入电流监测在硬件设计上存在，但当前遥测表/数据库没有提供对应的8路下行测点或代号。**

### 之江平台资源分配表

该表是PL负载供电、通信口和OC接口资源分配，不包含BCR PV支路输入电流或MPPT功率测点。

## 临时近似算法

在获取逐路输入电流前，只能用近似：

```text
V_PV_mean = mean(8路PV输入电压)
P_MPPT_approx = TMEA007 × V_PV_mean
P_BCR_out = Σ(V_BCR_out,j × I_BCR_out,j)
eta_BCR_approx = P_BCR_out / P_MPPT_approx
```

2026-07-28 16:15–17:15窗口试算：

- MPPT输入功率近似均值：201.06 W；
- 8路BCR输出功率和均值：120.34 W；
- 近似转换效率中位：56.9%，p05–p95约 -2.4%–66.4%。

该结果量级合理，但效率分布过宽，且部分分钟BCR输出为负值，尚不能作为正式MPPT功率模型。算术平均PV电压只有在8路输入电流相近时才成立；目前没有数据可证明这一点。

## 下一步需要补充

优先补充以下任一项：

1. 8路PV输入电流实际遥测代号及数据库列；
2. 8路MPPT输入功率直接遥测；
3. 各BCR输入-输出功率效率曲线或标定表；
4. 能证明`TMEA007`中各支路电流分配比例的接口说明。

取得其中一项后，才能把太阳阵目标从母线电压过渡代理改为：

```text
P_MPPT = Σ(V_PV,j × I_PV,j)
```

## 当前采用的替代方案

在8路PV输入电流补齐前，正式模型改用已经实测的BCR输出侧功率：

```text
P_BCR_out = Σ(V_BCR_out,j × I_BCR_out,j)
```

该量位于母线/电池公共功率节点，与SOC记账边界一致；硬件拓扑和遥测平衡见
[BCR拓扑核查](bcr_topology_audit.md)。
