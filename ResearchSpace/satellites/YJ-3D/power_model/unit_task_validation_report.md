# 云尖3D星单机任务模型留出验证

## 正确验证方式

- 从历史单机功率中提取稳定的`active/idle`状态变化，构造未来任务计划。
- 共10个片段、303条状态任务；常开常关且无状态变化的通道保留在背景负载。
- 单机模型排除全部验证日期后一次性重新校准，不是用全量模型自测。
- 太阳能模型也排除全部验证日期，A/B对比时保持不变，以隔离单机模型贡献。
- 观测目标SOC采用初始V-SOC锚点加独立`TMEA006`电流积分，属于条件参考，不是独立硬件SOC真值。

在无太阳封顶、保持太阳阵模型不变的公平对比中：

- 目标SOC MAE降低 `2.543 pp`。
- 剩余容量MAE降低 `0.959 Ah`。
- 负载能量MAE降低 `14.217 个百分点`。
- 太阳能量指标保持不变，说明改善来自任务单机模型和背景负载重新分解，而不是太阳阵调参。

## 结论和限制

- 单机任务模型确实能显著降低最终剩余电量误差，不能再按“`tasks=[]`所以单机模型无影响”评价。
- 当前任务状态由历史遥测提取，验证的是“未来工作状态已知时，单机功率模型能否算准”；它不验证任务状态本身能否提前预测。
- 09-11 00:59片段负载能量误差仍约-46.13%，说明背景负载或其他未测负载仍有明显问题。
- 观测目标SOC仍缺少多窗口独立SOC锚点，绝对Ah结果应按条件参考解释。
