# 云尖3D星太阳阵与SOC验证：2026-07-28 16:22–17:11

## 验证设计

- 49个连续阳照分钟。
- 训练集排除10个验证片段涉及的全部日期，留出太阳阵模型采用负载感知线性结构。
- 留出模型选择“时间一阶+未来预测负载”，分组CV RMSE约8.45 W；
  同一训练集纯时间一阶约20.69 W。
- 没有未来任务计划，负载按起始母线功率恒定。
- 起止蓄电池电压均落在7.84 A放电曲线范围内。
- 太阳阵训练与观测目标为`Σ(V_BCR_out,j×I_BCR_out,j)`。
- BCR输出已位于母线/电池公共节点，不再乘经验传输效率。
- 用户确认太阳阵控制逻辑为MPPT；默认模型不施加负载跟随封顶。
- `P_solar_to_bus <= total_load + margin`仅作为可选保守规划模式，不是MPPT控制律。

## 结论

负载感知BCR模型在本窗口的SOC误差约**3.64个百分点**，BCR输出侧太阳能量误差约**7.47%**。
0 W封顶可进一步改善该异常窗口，但封顶功率跟随负载，与MPPT控制逻辑不一致，
因此只能作为保守规划对照。BCR输出是MPPT/DC-DC后的母线侧功率，不是PV输入功率。

方向V-SOC候选同样不建议替换生产曲线：充电方向SOC映射MAE由3.24个百分点恶化到
10.47个百分点。当前SOC结果只能作为条件演示，不能作为全时段SOC或SOH结论。

## 证据边界

- BCR输出是MPPT/DC-DC后的母线侧功率，不是PV输入或阵列片端实测功率。
- 负荷跟随封顶是可选保守任务规划约束，不是MPPT控制律或电池充电接受能力。
- 8路PV输入电压约37–43 V，但当前缺少8路PV输入电流。
- 8路BCR输出均值和`TMEA003×TMEA007`均值仅相差约1.25 W，
  因此本次低输出不是单个太阳电流测点损坏造成的。
- `TMEA004`负载覆盖、`TMEA006`传感器指向和BCR/母线/电池边界仍待连接图确认。
- 7.84 A放电曲线不能覆盖大多数充电电压；本窗口仅因起止电压落在曲线内而被选中。
- 温度、太阳入射角、姿态、分流工作点、充电滞回和真实SOC锚点均未建模。
