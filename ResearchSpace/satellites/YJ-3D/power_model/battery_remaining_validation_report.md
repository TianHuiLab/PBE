# 云尖3D星电池剩余电量预测验证

## 结论

当前结果不能作为飞行级绝对剩余电量结论。

本报告是无任务基线；单机模型不能由`tasks=[]`结果评价，正确验证见
[单机任务模型留出验证](unit_task_validation_report.md)。

- 只有2026-07-28片段的起止电池电压同时落在7.84 A V-SOC表内，可做条件绝对SOC对比。
- 其余9个片段只能用独立`TMEA006`电流积分验证ΔSOC/ΔAh，没有真实SOC锚点。
- 当前0 W保守模型在唯一绝对窗口的SOC误差为**2.9306个百分点**，剩余电量误差为**1.105 Ah / 0.0279 kWh（额定）**。
- 10片段ΔSOC MAE为**3.778个百分点 / 1.424 Ah / 0.0360 kWh**，但p95为**10.756个百分点 / 4.054 Ah / 0.1024 kWh**。
- 10个片段中7个落在±5个百分点内，只有8个落在±10个百分点内，尾部精度不足。

## 判定

- 如果验收要求是大部分片段在±5个百分点/±2 Ah内：当前中位数和MAE接近，但约有3/10片段不满足，未通过。
- 如果要求p95在±5个百分点或±2 Ah内：当前p95约10.76个百分点/4.05 Ah，明确未通过。
- 若要支持绝对剩余电量验收，至少需要独立SOC锚点、充电效率/滞回标定以及可核验的电池测点边界。
