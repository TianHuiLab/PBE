# 卫星整星能源平衡定量评估框架

## ——基于三体星遥测数据的实证分析

## 1. 框架概述

### 1.1 评估目标

本框架旨在建立一套基于实际遥测数据的卫星整星能源平衡定量评估方法，实现：
- **实时能源状态监测**：基于遥测参数计算即时能源供需状态
- **能量平衡定量评估**：计算能源裕度、蓄电池SOC等关键指标
- **性能趋势分析**：跟踪电源系统性能衰减趋势
- **异常预警**：识别能源系统潜在风险

### 1.2 评估范围

**评估对象**：三体星01星电源系统
**数据来源**：三体星遥测大表（01星/02星/遥控遥测大表）
**评估周期**：轨道周期级（约90-120分钟/圈）

### 1.3 框架结构

```
数据层 → 参数层 → 指标层 → 评估层
  ↓        ↓        ↓        ↓
遥测数据  物理量   性能指标  评估结论
```

## 3. 参数层：物理量计算

### 3.1 发电功率计算

#### 3.1.1 单帆板发电功率
```
P_panel_i(t) = V_panel_i(t) × I_panel_i(t)    [W]
```
其中：`i ∈ {A, B, C, D, E, F}`

#### 3.1.2 太阳阵总发电功率
**方法1：各帆板功率求和**
```
P_solar_total(t) = Σ P_panel_i(t) = Σ [V_i(t) × I_i(t)]
```

**方法2：总电流法（简化）**
```
P_solar_total(t) = V_bus_avg(t) × I_solar_total(t)
```
其中：`V_bus_avg` 为母线平均电压（各帆板电压近似）

#### 3.1.3 帆板健康度评估
```
η_panel_i(t) = P_panel_i(t) / P_panel_rated
```
其中：`P_panel_rated` 为帆板标称功率（需设计参数）

### 3.2 负载功率计算

#### 3.2.1 母线总负载功率
```
P_load_total(t) = V_bus(t) × I_bus(t)    [W]
```

#### 3.2.2 各分系统负载功率

**姿控系统功率**：
```
P_attitude(t) = V_bus × (I_wheel1 + I_wheel2 + I_wheel3 + I_wheel4 + I_gyro)
```

**测控系统功率**：
```
P_TT&C(t) = V_A×I_A + V_B×I_B + V_TDS×I_TDS + V_PA×I_PA
```
其中：
- `V_A, I_A`：测控应答机A机
- `V_B, I_B`：测控应答机B机
- `V_TDS, I_TDS`：测控数传
- `V_PA, I_PA`：测控相控阵

**通信系统功率**：
```
P_comm(t) = V_bus × (I_microwave1A + I_microwave1B + I_microwave2A + I_microwave2B + I_laser1 + I_laser2)
```

**计算系统功率**：
```
P_compute(t) = V_bus × (I_NX1F + I_NX1G + I_G1 + I_G2 + I_R1_main + I_R1_backup)
```

**科学载荷功率**：
```
P_payload(t) = V_bus × I_CXPD + V_camera × I_camera
```
（注：相机功率需补充工作电流参数）

**电推进系统功率**：
```
P_propulsion(t) = V_bus × (I_ep_A + I_ep_B)
```

#### 3.2.3 负载功率验证
```
P_load_calculated = Σ P_subsystem
P_load_measured = V_bus × I_bus
验证误差 = |P_load_calculated - P_load_measured| / P_load_measured × 100%
```
要求：误差 < 5%

### 3.3 蓄电池功率计算

#### 3.3.1 充放电功率
根据功率平衡：
```
P_battery(t) = P_solar_total(t) - P_load_total(t) - P_loss(t)
```
简化（忽略损耗）：
```
P_battery(t) ≈ P_solar_total(t) - P_load_total(t)
```

- `P_battery > 0`：蓄电池放电
- `P_battery < 0`：蓄电池充电

#### 3.3.2 充放电电流
```
I_battery(t) = P_battery(t) / V_battery(t)
```

#### 3.3.3 充放电状态判断
```
Status_battery(t) = {
    "充电",  if I_battery < -I_threshold
    "放电",  if I_battery > I_threshold
    "浮充",  if |I_battery| ≤ I_threshold
}
```
其中：`I_threshold` 为充放电阈值（建议0.1A）

### 3.4 系统损耗计算

#### 3.4.1 PCDU损耗
```
P_loss_PCDU(t) = P_solar_total(t) + P_battery_discharge(t) - P_load_total(t)
```

#### 3.4.2 二次电源损耗
```
P_loss_DCDC(t) = P_DCDC_in(t) - P_DCDC_out(t)
```
（需补充二次电源输入电流参数）

#### 3.4.3 线路损耗估算
```
P_loss_line(t) ≈ I_bus²(t) × R_line
```
其中：`R_line` 为线路等效电阻（设计参数，通常<0.1Ω）

## 4. 指标层：性能评估指标

### 4.1 能量平衡指标

#### 4.1.1 瞬时功率裕度
```
M_power(t) = [P_solar_total(t) - P_load_total(t)] / P_load_total(t) × 100%
```
- **正常范围**：M_power > 20%（光照期）
- **警戒值**：0% < M_power < 20%
- **危险值**：M_power < 0%（需蓄电池补充）

#### 4.1.2 轨道能量平衡
对单个轨道周期积分：
```
E_solar_orbit = ∫[0,T_orbit] P_solar_total(t) dt    [Wh]
E_load_orbit = ∫[0,T_orbit] P_load_total(t) dt    [Wh]
E_battery_net = E_solar_orbit - E_load_orbit    [Wh]
```

**轨道能量裕度**：
```
M_orbit = (E_solar_orbit - E_load_orbit) / E_load_orbit × 100%
```
- **设计要求**：M_orbit ≥ 15-20%

#### 4.1.3 日均能量平衡
```
E_solar_day = Σ E_solar_orbit(i)    [Wh/天]
E_load_day = Σ E_load_orbit(i)    [Wh/天]
M_day = (E_solar_day - E_load_day) / E_load_day × 100%
```

### 4.2 蓄电池状态指标

#### 4.2.1 荷电状态（SOC）估计
**方法1：安时积分法**
```
SOC(t+1) = SOC(t) + ∫[t,t+1] I_battery(τ) dτ / C_battery × 100%
```
其中：
- `I_battery`：充放电电流（充电为负，放电为正）
- `C_battery`：蓄电池标称容量（Ah，需设计参数）

**方法2：开路电压法（校准）**
```
SOC = f(V_battery_oc)
```
其中：`V_battery_oc` 为蓄电池开路电压（需充放电曲线）

**方法3：混合估计（推荐）**
```
SOC(t) = α × SOC_Ah(t) + (1-α) × SOC_OCV(t)
```
其中：`α` 为权重系数（通常0.9-0.95）

#### 4.2.2 放电深度（DoD）
```
DoD(t) = 1 - SOC(t)
DoD_max = max[DoD(t)]    [轨道周期内]
```
- **设计要求**：DoD_max ≤ 30-40%（保证寿命）
- **警戒值**：DoD > 50%

#### 4.2.3 充放电效率
```
η_battery = E_discharge / E_charge × 100%
```
- **典型值**：85-95%（锂离子电池）
- **衰减判据**：η_battery < 80% 需关注

#### 4.2.4 蓄电池健康状态（SOH）
```
SOH(t) = C_actual(t) / C_nominal × 100%
```
其中：`C_actual` 通过充放电测试估计

### 4.3 发电系统指标

#### 4.3.1 太阳阵输出功率
```
P_solar_max = max[P_solar_total(t)]    [轨道周期内]
P_solar_avg = mean[P_solar_total(t)]    [光照期平均]
```

#### 4.3.2 帆板利用率
```
η_utilization = P_solar_avg / P_solar_rated × 100%
```
其中：`P_solar_rated` 为太阳阵标称功率（需设计参数）

#### 4.3.3 帆板一致性
```
CV_panel = std[P_panel_i] / mean[P_panel_i] × 100%
```
- **要求**：CV < 10%（帆板性能一致性）

#### 4.3.4 性能衰减率
```
η_degradation = [P_solar(t) - P_solar(t-1年)] / P_solar(t-1年) × 100% / 年
```
- **典型值**：2-3%/年（GaAs电池）

### 4.4 配电系统指标

#### 4.4.1 母线电压稳定度
```
ΔV_bus = [max(V_bus) - min(V_bus)] / V_bus_nominal × 100%
```
- **要求**：ΔV_bus < 5%

#### 4.4.2 母线电压纹波
```
V_ripple = V_bus_peak-peak / V_bus_nominal × 100%
```
- **要求**：V_ripple < 1%

#### 4.4.3 负载平衡度
```
Load_imbalance = max(P_subsystem) / mean(P_subsystem) - 1
```
- **要求**：Load_imbalance < 50%（避免单支路过载）

### 4.5 系统效率指标

#### 4.5.1 一次电源效率
```
η_primary = P_load_total / (P_solar_total + P_battery_discharge) × 100%
```
- **典型值**：90-95%

#### 4.5.2 能源利用效率
```
η_system = E_load_useful / E_solar_total × 100%
```
其中：`E_load_useful` 为有效负载能耗（排除热控等辅助系统）

#### 4.5.3 能源冗余度
```
Redundancy = (P_solar_rated - P_load_max) / P_load_max × 100%
```
- **要求**：Redundancy ≥ 30%

## 5. 评估层：综合评估方法

### 5.1 能源健康度评分

#### 5.1.1 指标标准化
对各项指标进行标准化处理：
```
Score_i = {
    100,                    if Metric_i ≥ Target_i
    (Metric_i - Threshold_i) / (Target_i - Threshold_i) × 100,  if Threshold_i < Metric_i < Target_i
    0,                      if Metric_i ≤ Threshold_i
}
```

#### 5.1.2 权重分配
| 指标类别 | 权重 | 包含指标 |
|---------|------|---------|
| 能量平衡 | 0.35 | 功率裕度、轨道能量裕度 |
| 蓄电池状态 | 0.30 | SOC、DoD、SOH |
| 发电系统 | 0.20 | 帆板利用率、一致性 |
| 配电系统 | 0.15 | 母线稳定度、效率 |

#### 5.1.3 综合评分
```
Health_score = Σ (Weight_i × Score_i)
```
- **优秀**：90-100分
- **良好**：75-89分
- **一般**：60-74分
- **较差**：<60分

### 5.2 异常检测与预警

#### 5.2.1 阈值预警
| 参数 | 正常范围 | 预警值 | 报警值 |
|------|---------|--------|--------|
| 母线电压 | 26-30V | <25V或>31V | <24V或>32V |
| 蓄电池电压 | 24-32V | <23V或>33V | <22V或>34V |
| 蓄电池温度 | 0-30℃ | <-5℃或>35℃ | <-10℃或>40℃ |
| 功率裕度 | >20% | 10-20% | <10% |
| DoD | <30% | 30-40% | >40% |

#### 5.2.2 趋势预警
基于历史数据拟合：
```
Trend = d(Metric)/dt
```
- **趋势恶化**：连续7天指标下降
- **预测寿命**：基于衰减率外推

#### 5.2.3 关联分析
多参数联合判断：
- **太阳阵失效**：某帆板功率突降 + 总功率下降
- **蓄电池劣化**：DoD持续增加 + 效率下降
- **负载异常**：某支路电流突增 + 母线电压波动

### 5.3 典型工况评估

#### 5.3.1 光照期评估
- **评估重点**：发电能力、充电效率
- **关键指标**：P_solar、η_charge、SOC变化率
- **判据**：
  - 发电功率 ≥ 负载功率 × 1.2
  - SOC逐渐回升至满充

#### 5.3.2 地影期评估
- **评估重点**：蓄电池放电能力、负载管理
- **关键指标**：DoD、放电深度、最低SOC
- **判据**：
  - DoD ≤ 30%
  - SOC_min ≥ 50%

#### 5.3.3 峰值负载评估
- **评估重点**：瞬时功率平衡、母线稳定度
- **关键指标**：P_peak、ΔV_bus、响应时间
- **判据**：
  - 峰值功率 ≤ 太阳阵额定功率
  - 母线电压波动 < 5%

def evaluate_energy_balance(telemetry_data):
    # 1. 计算发电功率
    P_solar = calculate_solar_power(telemetry_data)
    
    # 2. 计算负载功率
    P_load = calculate_load_power(telemetry_data)
    
    # 3. 计算蓄电池功率
    P_battery = P_solar - P_load
    
    # 4. 估计蓄电池SOC
    SOC = estimate_battery_SOC(P_battery, telemetry_data)

    metrics = calculate_metrics(P_solar, P_load, P_battery, SOC)
    
    # 6. 综合评估
    health_score = calculate_health_score(metrics)
    
    # 7. 异常检测
    anomalies = detect_anomalies(telemetry_data, metrics)
    
    return {
        'metrics': metrics,
        'health_score': health_score,
        'anomalies': anomalies
    }
