```
s1_fetch.py ──▶ data_power_minute.csv ──▶ s3_run.py ──▶ out/energy_v2_*.csv ──▶ gen_charts.py ──▶ charts/*.svg + framework_documentation.html
(ClickHouse        (分钟聚合遥测)          (energy_balancer        (指标/日报)            (离线内嵌,
```

| 模块 | 职责 |
|------|------|
| `ch_http.py` | ClickHouse HTTP 客户端（stdlib only，口令走环境变量/.env） |
| `energy_balancer.py` | **v2.1 评估内核**（唯一正规算法模块：物理量→工况→SOC/充放→能量闭合→健康度） |
| `s1_fetch.py` | 从 ClickHouse 拉取电源遥测，分钟聚合落地 CSV |

| `gen_charts.py` | 由评估输出生成 SVG 图表并无痕内嵌 HTML 文档 |
| `test_chart_documentation.py` | 图表/HTML 嵌入回归测试（8 用例） |
| `tests/test_energy_balancer.py`、`tests/test_ch_http.py` | v2 内核与 HTTP 客户端单元测试 |
| `config/` | 单一事实源：设计参数、V-SOC 曲线、遥测参数映射（JSON） |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt   # pandas / numpy（clickhouse-driver 仅 04/05 需要）
```

### 2. 配置数据库口令（不写死在代码里）

```bash
# 方式一：环境变量
export CH_PASSWORD='<查询口令>'      # Windows PowerShell: $env:CH_PASSWORD='...'

# 方式二：同目录 .env 文件（已被 .gitignore 排除）
cp .env.example .env   # 然后编辑 .env 填入 CH_PASSWORD
```

可选项：`CH_HOST`（默认 10.200.56.174）、`CH_PORT`（HTTP 8123 / 原生 9000）、
`CH_USER`（默认 default）、`CH_DB`（默认 chdb_3body）。

### 3. 运行 v2 评估链

```bash
python s1_fetch.py    # ① 拉取遥测 → data_power_minute.csv（需内网+口令）
python s3_run.py      # ② v2 评估 → out/energy_v2_result.csv 等（含闭合校验输出）
python gen_charts.py  # ③ 图表 + HTML 文档同步（纯标准库，可离线重复运行）
```

### 4. 运行测试

```bash
python -m pytest tests/ -q          # 或: python -m unittest discover -s tests -v
```

## 核心口径（v2.1，2026-10-22 起）

电源拓扑为 **S3R（顺序开关分流调节）**：太阳阵直接耦合母线，分流级在 PCU 内部消耗富余、不流经母线测点。因此：

- **发电功率 = 母线电压 × 母线电流（TMD016 × TMD017）**——实际送达母线的发电，分流已被测点上游扣除，**不再单独建模分流**；
- **负载功率 = V_bus × I_load（TMD018）**；
- **分流为诊断量**：`P_shunt_diag = (I_solar(TMD009) − I_bus(TMD017)) × V_bus`（帆板级-母线级独立测点差额，≈ S3R 分流+PCU 损耗，应 ≥0）；
- **日照/地影判定用帆板级 TMD009**（光照工况本身，不受分流影响）。

## 真实数据评估（v2.1 阶段成果）

- **数据源**：ClickHouse 集群 `prod_cluster` → `chdb_3body.telemetry_raw_01`（真实在轨遥测）
- **评估对象**：SCS-01-01 三体星 01 星，观测 2025-12-27 ~ 2026-08-10（4738 分钟样本）
- **综合健康度**：73 分（一般/关注）；入母线口径功率裕度 81.9%；关注点在地影期电池深放电（DoD p95≈53%）
- **能量收支**（观测窗口 kWh）：日照 发电(入母线) 23.91 = 负载 13.14 + 充电 12.62 − 放电 1.86；帆板级 39.46 = 入母线 23.91 + 分流诊断 15.55，双向闭合自洽
- **核心工具**：[energy_balancer.py](energy_balancer.py)（评估器）＋ [ch_http.py](ch_http.py)（ClickHouse HTTP 客户端）
- 关键产出明细见 [09 框架](09_评估框架设计_v2_真实数据实证.md) 与 [10 评估报告](10_真实数据评估报告_SCS-01-01.md)
- ⚠ 引用发电量/裕度时须注明"入母线口径"；帆板级口径数值更大但含被分流部分，仅作诊断

## 核心评估指标

| 指标 | 正常范围 | 预警阈值 | 说明 |
|------|---------|---------|------|
| 功率裕度 | >20% | <10% | (发电功率-负载功率)/负载功率 |
| 放电深度DoD | <30% | >40% | 蓄电池放电深度 |
| 荷电状态SOC | >50% | <40% | 蓄电池剩余电量 |
| 帆板利用率 | >60% | <40% | 太阳阵发电效率 |
| 母线稳定度 | <3% | >5% | 配电母线电压稳定性 |

## 工程约定

- **参数单一事实源**：设计参数、V-SOC 曲线、遥测代号映射均在 `config/*.json`，改参数只改配置不改代码；
- **产物目录**：`out/`（评估输出 CSV）、`charts/`（SVG 副本）均为可再生产物，已被 `.gitignore` 排除；
- **数据文件**：`data_power_minute.csv` 由 `s1_fetch.py` 生成，不入库（大文件），复现请重跑该脚本；
- **一次性脚本**：`q1–q5`、`s2/s4/s5` 为探索/诊断脚本，结论已沉淀进 09/11 号文档；
- **凭据**：任何口令不得写进代码，一律走环境变量或 `.env`。
