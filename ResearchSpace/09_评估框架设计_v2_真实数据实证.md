## 1. 框架总览

本框架基于**真实在轨遥测**建立整星能源平衡的定量评估方法，链路为：

```
数据层 → 参数层 → 物理量 → 工况划分 → 储能状态 → 能量平衡 → 指标与健康度
  ↓        ↓        ↓        ↓          ↓           ↓          ↓
长期遥测  电源参数  功率/电压  日照/地影    SOC/DoD    收支·闭合   评分·预警
```

设计目标：
- **能量守恒闭合**：发电 = 负载 + 电池净交换 + 分流（给出残差，保证模型自洽）；
- **工况可解释**：日照段（发电/充电/分流）与地影段（放电/深放电）分别量化；
- **真实数据驱动**：关键参数直接从遥测导出，SOC = 电压锚定，不臆造数值；
- **抗毛刺**：指标统计采用稳健百分位（p5/p95/中位数），全局极值单列告警。

## 3. 参数层：物理量计算

### 3.1 发电功率
```
P_solar(t) = I_solar_total(TMD009, t) × V_bus(t)      [W]
```
- 平均 500 W（含地影）、日照典型 539-650 W、峰值 780 W。

### 3.2 负载功率（主口径）
```
P_load(t) = I_load(TMD018, t) × V_bus(t)              [W]
P_bus(t)  = I_bus(TMD017, t) × V_bus(t)               [W，交叉校验，含充电]
```
- 日照平均 ~180 W；地影段负载 ~286 W（深放电工况）。

### 3.3 功率富余 / 缺口
```
P_excess(t) = P_solar(t) - P_load(t)                  [>0 富余；<0 缺口]
```

## 4. 工况划分

以太阳阵总电流为判据，5 样本中心滚动窗口**多数表决**（窗口内光照样本占比 ≥ 0.5），抗单点毛刺：
```
phase(t) = 日照(光照)   if mean₅(1[I_solar ≥ 1.0 A]) ≥ 0.5
           地影(阴影)   otherwise
```
- 观测样本日照占比 ~92.7%，地影样本 347-568 个。
- 注：早期表述"5 分钟滚动中值"与实现（`rolling(5, center=True).mean() ≥ 0.5`，布尔多数表决）不符，已按实现修正；两者抗毛刺效果等价。

## 5. 储能状态估计（SOC / DoD）

**方法：逐样本电压锚定 SOC**（对突发采样数据最诚实，天然反映浮充与放电）
```
SOC(t) = f(V_bat(t))          锂电池 开路电压→SOC 校准曲线（分段线性）
DoD(t) = 1 - SOC(t)
```
- **分流模型**：当 SOC ≥ 95%（分流阈值）时，日照富余功率计为「分流」，不再无限计入充电；
- **极端值单列**：DoD 用 p95、SOC 用 p5 参与评分，全局 min SOC 仅作告警标记。

真实结果：
- 日照段 SOC ≈ 87%（p50），电池接近满充、处于浮充/浅循环；
- 地影段 SOC 降至 ~47%（p50），部分深放电通过 DoD p95 ≈ 53% 表现；
- 全局绝对 min SOC ≈ 5%（应为遥测毛刺/瞬时，单列并标记复核）。

## 6. 能量平衡与守恒闭合

**记账式**：`E_solar = E_load + E_battery_net + E_shunt + residual`
- E_battery_net = E_charge + E_disch（充电为正，放电为负）；
- E_shunt = 满充后未被电池吸收、被分流掉的富余能量；
- residual = 记账残差。

> **⚠ 闭合口径澄清（2026-10-21 实证）**：由于 `P_charge + P_disch + P_shunt ≡ P_excess`
> 由模型构造保证，`residual` **恒等于 0**（对真实数据核验：0.000000 kWh），
> 它是记账恒等式，**不具备模型校验能力**，不能作为"闭合通过"的证据。
> 唯一有判别力的校验是**独立遥测通道**——用 TMD017 母线需求反推：
> `E_bus_residual = E_bus − E_load − E_charge`（应 ≈ 0）。

真实能量统计（观测窗口，kWh；每观测分钟按 1/60 h 折算，不对外推）：

| 工况 | 发电 | 负载 | 母线需求 | 充电 | 放电 | 分流 |
|------|------|------|----------|------|------|------|
| 日照 | 39.43 | 13.14 | 23.89 | +20.32 | −1.40 | 7.37 |
| 地影 | 0.08 | 1.84 | 0.02 | 0.00 | −1.77 | 0.00 |

**母线通道交叉校验（待查项）**：`E_bus_residual = 23.91 − 14.99 − 20.33 = −11.41 kWh`（占母线需求 **−47.7%**）；
若改按"分流电流经母线测点"假设（`E_bus − E_load − E_shunt`）则仅 +1.55 kWh（+6.5%）。
两种拓扑假设结论相反，当前数据不足以定论。排查路径：
① 对照《三体星_遥控遥测大表》确认 TMD017 测量点定义（充电/分流电流是否流经该测点）；
② 若分流假设成立，说明电压锚定 SOC 系统性偏低（富余多计为充电），需用电池电流遥测
（库仑交叉）标定 V-SOC 曲线后复核。该偏差不影响功率裕度、母线稳定度等结论，
但影响 SOC/DoD 绝对值与充/分流能量拆分。

## 8. 评估结论（真实数据）

1. **能量供给极其充裕**：功率裕度约 200%，太阳阵大幅过设计，多数时间内、日照段发电远超负载。
2. **主要风险在储能深放电**：地影段蓄电池 DoD 最坏 5% 达到约 53%（超过常规 50% 关注线），需重点监测地影 + 高负载（通信/激光/载荷）叠加时的电池状态。
3. **调度窗口**：母线稳定度 4.6% 略超 3% 目标，与地影/高负载切换有关。
4. **运行建议**：地影前预留 SOC 安全裕度；大功率载荷尽量安排在日照段；持续跟踪 DoD>50% 事件频次评估电池寿命消耗。
