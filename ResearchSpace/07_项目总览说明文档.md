# 卫星整星能源分析项目

## 项目概述

本项目针对三体星卫星，开展整星能源分析调研，并基于实际遥测数据建立能源平衡定量评估框架。

## 研究流程与文件清单

本项目按照以下顺序开展，文件按研究流程编号：

```
1. 技术调研 → 2. 框架构计 → 3. 工具开发 → 4. 数据库对接 → 5. 数据分析 → 6. 报告生成 → 7-8. 总结归档
```

## 交付物清单

### 1. 调研报告

**文件**: `01_技术调研报告_卫星整星能源分析.md`

**内容**:
- 卫星能源系统组成与原理
- 能源平衡分析方法论
- 在轨性能评估方法
- 能源优化策略
- 三体星能源系统特点分析

**核心要点**:
- 能源平衡遵循能量守恒：E_generation = E_consumption + E_storage + E_loss
- 关键指标：功率裕度（≥20%）、放电深度DoD（≤30%）、蓄电池SOC
- 三体星配备6个太阳帆板（A-F），可独立监测电压电流
- 主要负载包括：姿控、测控、通信、计算、科学载荷等系统

### 2. 评估框架

**文件**: `02_评估框架设计_能源平衡定量评估.md`

**内容**:
- 完整的遥测参数体系（126个电源分系统参数）
- 物理量计算方法（发电功率、负载功率、蓄电池状态）
- 性能评估指标体系（能量平衡、蓄电池状态、发电/配电系统）
- 综合评估方法（健康度评分、异常检测、预警机制）
- 评估报告模板（日报、月报）

**框架结构**:
```
数据层 → 参数层 → 指标层 → 评估层
  ↓        ↓        ↓        ↓
遥测数据  物理量   性能指标  评估结论
```

**关键公式**:
- 太阳阵功率：P_solar = Σ(V_panel_i × I_panel_i)
- 负载功率：P_load = V_bus × I_bus
- 蓄电池SOC：SOC(t+1) = SOC(t) + I_battery × dt / C_battery
- 功率裕度：M_power = (P_solar - P_load) / P_load × 100%
- 健康度评分：Health = Σ(Weight_i × Score_i)

### 3. 评估工具

**文件**: `03_核心评估工具_能源平衡评估器.py`

**功能**:
- `SatelliteEnergyBalancer` 类：核心评估器
- `calculate_solar_power()`: 计算太阳阵发电功率
- `calculate_load_power()`: 计算各分系统负载功率
- `calculate_battery_power()`: 计算蓄电池功率和SOC
- `calculate_metrics()`: 计算性能评估指标
- `evaluate_health()`: 评估系统健康度
- `detect_anomalies()`: 异常检测
- `generate_report()`: 生成Markdown格式报告

**使用方法**:
```python
# 从核心评估工具导入
import sys
sys.path.append('.')
exec(open("03_核心评估工具_能源平衡评估器.py").read())
import pandas as pd

# 创建评估器
evaluator = SatelliteEnergyBalancer(satellite_id="01星")

# 加载遥测数据（从Excel或CSV）
telemetry = pd.read_excel("01星遥测大表.xlsx")
evaluator.load_telemetry_data(telemetry)

# 运行评估
metrics = evaluator.calculate_metrics()
health = evaluator.evaluate_health()
report = evaluator.generate_report()

# 保存报告
with open("energy_report.md", 'w') as f:
    f.write(report)
```

**演示运行**:
```bash
python3 03_核心评估工具_能源平衡评估器.py
```

## 三体星能源系统特点

### 遥测参数覆盖

基于01星遥测大表，电源分系统包含126个参数：

| 子系统 | 参数数量 | 主要监测内容 |
|--------|---------|-------------|
| PCDU | 97 | 母线V/I、各负载电流、温度、开关状态 |
| 太阳阵 | 13 | 6个帆板的V/I（独立+汇总） |
| 蓄电池 | 4 | 电压、温度、开关状态 |
| 智算机路由器 | 6 | 高性能计算模块电流 |
| 测控应答机 | 4 | A/B机电压电流 |
| 测控数传 | 2 | 数传上注电压电流 |

### 核心监测参数

**发电侧**:
- TMD003-TMD008: 太阳阵A-F电压
- TMD010-TMD015: 太阳阵A-F电流
- TMD009: 太阳阵总电流

**储能侧**:
- TMD019: 蓄电池电压
- TMD080: 蓄电池温度

**配电侧**:
- TMD016: 母线电压
- TMD017: 母线电流
- TMD018: 负载电流

**负载侧**:
- TMD045-TMD048: 反作用轮1-4电流
- TMD049-TMD054: 测控系统电压电流
- TMD031-TMD044: 通信系统电流
- TMD025-TMD030: 计算系统电流
- TMD066: 科学载荷电流

## 评估指标体系

### 能量平衡指标

| 指标 | 计算公式 | 正常范围 | 预警值 |
|------|---------|---------|--------|
| 功率裕度 | (P_solar - P_load) / P_load × 100% | >20% | <10% |
| 轨道能量裕度 | (E_solar - E_load) / E_load × 100% | >15% | <10% |
| 日均能量平衡 | E_solar_day / E_load_day | >1.2 | <1.1 |

### 蓄电池状态指标

| 指标 | 计算公式 | 正常范围 | 预警值 |
|------|---------|---------|--------|
| SOC | 安时积分法 | >50% | <40% |
| DoD | 1 - SOC | <30% | >40% |
| 充放电效率 | E_discharge / E_charge | 85-95% | <80% |

### 发电系统指标

| 指标 | 计算公式 | 正常范围 | 预警值 |
|------|---------|---------|--------|
| 帆板利用率 | P_solar_avg / P_solar_rated | >60% | <40% |
| 帆板一致性 | std(P_panel) / mean(P_panel) | <10% | >15% |
| 性能衰减率 | ΔP / Δt | <3%/年 | >5%/年 |

### 配电系统指标

| 指标 | 计算公式 | 正常范围 | 预警值 |
|------|---------|---------|--------|
| 母线稳定度 | ΔV_bus / V_nominal | <3% | >5% |
| 一次电源效率 | P_load / (P_solar + P_bat_discharge) | >90% | <85% |

## 健康度评分模型

### 评分权重

| 指标类别 | 权重 | 包含指标 |
|---------|------|---------|
| 能量平衡 | 0.35 | 功率裕度、轨道能量裕度 |
| 蓄电池状态 | 0.30 | SOC、DoD、SOH |
| 发电系统 | 0.20 | 帆板利用率、一致性 |
| 配电系统 | 0.15 | 母线稳定度、效率 |

### 健康等级

| 评分范围 | 健康等级 | 建议措施 |
|---------|---------|---------|
| 90-100 | 优秀 | 继续保持 |
| 75-89 | 良好 | 常规监测 |
| 60-74 | 一般 | 加强监测，制定预案 |
| <60 | 较差 | 立即排查，采取措施 |

## 使用流程

### 1. 数据准备

从遥测大表提取以下参数：
```python
required_params = [
    'TMD003', 'TMD004', 'TMD005', 'TMD006', 'TMD007', 'TMD008',  # 帆板电压
    'TMD010', 'TMD011', 'TMD012', 'TMD013', 'TMD014', 'TMD015',  # 帆板电流
    'TMD009',  # 总电流
    'TMD016', 'TMD017', 'TMD018',  # 母线参数
    'TMD019', 'TMD080',  # 蓄电池参数
    # ... 其他负载电流参数
]
```

### 2. 数据预处理

- 异常值剔除（超出物理范围的值）
- 缺失值插值（线性插值或样条插值）
- 时间对齐（多参数同步）

### 3. 运行评估

```python
# 完整评估流程
evaluator = SatelliteEnergyBalancer()
evaluator.load_telemetry_data(telemetry_data)
evaluator.calculate_solar_power()
evaluator.calculate_load_power()
evaluator.calculate_battery_power()
metrics = evaluator.calculate_metrics()
health = evaluator.evaluate_health()
anomalies = evaluator.detect_anomalies()
report = evaluator.generate_report()
```

### 4. 结果分析

- 查看健康度评分和分项得分
- 分析功率裕度和能量平衡
- 检查蓄电池SOC和DoD
- 识别异常事件和预警信息
- 根据建议措施制定改进方案

### 5. 报告生成

自动生成Markdown格式报告，包括：
- 健康度评分
- 能量平衡分析
- 蓄电池状态
- 配电系统评估
- 异常与预警
- 建议措施
