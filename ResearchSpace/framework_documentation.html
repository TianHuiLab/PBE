1框架概述

目标：基于三体星 SCS-01-01 的真实在轨遥测，定量评估整星能源系统健康度，识别能源风险（尤其地影期蓄电池深放电），并为任务规划提供能源约束参考。

数据层 · 遥测→ 参数层 · 电源物理量→ 工况划分 · 日照/地影→ 储能状态 · SOC/DoD→ 能量守恒闭合→ 指标与健康度

设计原则：全部物理量由真实遥测导出、不臆造数据；模型必须满足能量守恒（残差≈0）；统计口径抗毛刺（用稳健百分位而非全局极值）；风险单独标记验证。

核心能力：发电量统计、负载功耗测算、地影/日照识别、蓄电池荷电状态估算、能量收支平衡与健康度评分。

3实现原理与物理模型

3.1 功率物理量计算（v2.1 口径）

Psolar(t) = Ibus(TMD017, t) × Vbus(t)　（发电：实际送达母线，S3R 分流已扣除） Pload(t) = Iload(TMD018, t) × Vbus(t)　（主负载） Pshunt_diag(t) = (Isolar(TMD009, t) − Ibus(TMD017, t)) × Vbus(t)　（诊断：帆板级−母线级差额 ≈ S3R 分流+PCU 损耗） Pexcess(t) = Psolar(t) − Pload(t)　（>0 富余→充电 / <0 缺口→放电）

对物理量做上下限裁剪（如 V_bus 裁剪到 [10,45]，I_solar/I_load 裁剪到 [0,100]，I_bus 允许 [-5,100]）以抑制明显坏值。

3.2 日照 / 地影工况划分

以帆板级太阳阵总电流 TMD009为判据（光照工况本身，不受 S3R 分流影响——满充分流时母线电流很小但仍是日照），对 5 个样本的中心滚动窗口做多数表决（窗口内光照样本占比 ≥ 0.5 判日照），减小瞬时毛刺误判：

phase(t) = 日照　若 mean₅(1[Isolar(TMD009) ≥ Isun,thr]) ≥ 0.5（Isun,thr 默认 1.0 A）；否则 地影

注 1：早期文档表述为"5 分钟滚动中值"，实现自 v2 起为布尔多数表决（rolling(5, center=True).mean() ≥ 0.5），两者抗毛刺效果等价，此处按实现修正。注 2：在 >3×dt 的时间缺口处先切段再滚动，避免突发采样中"索引相邻但时间隔数日"的样本被同一窗口平滑。

3.3 蓄电池 SOC 估计（逐样本电压锚定）

真实遥测为突发采样，若用纯库仑积分会因采样缺口累积漂移。因此采用逐样本电池电压→SOC 映射：

SOC(t) = f(Vbat(t))　（分段线性插值，见 §4.4） DoD(t) = 1 − SOC(t)

3.4 分流处理（v2.1：由 S3R 测点隐含扣除，不再建模）

S3R 拓扑下，满充分流在 PCU 内部完成、不流经母线测点：母线电流 TMD017 本身已扣除被分流的部分。因此富余功率全部计充电，不需要也不应再用 SOC 阈值拆分（v2.0 的 soc_high=0.95 分流判定已移除）：

若 Pexcess ≥ 0 → Pcharge = Pexcess；若 Pexcess < 0 → Pdisch = Pexcess（电池净获电，负值为放电）

满充后 S3R 自动分流，母线电流随之下降、充电自然趋 0——分流行为由物理测点真实反映，而非模型推断。

3.5 能量守恒闭合

Esolar = Eload + Ebattery,net + ε（记账残差）

重要澄清：由于 Pcharge+Pdisch ≡ Pexcess ≡ Psolar−Pload 由模型构造保证，ε 恒等于 0（已对真实数据核验：ε = 0.000000 kWh）——它是记账恒等式，不具备模型校验能力，不能作为"闭合通过"的证据。

v2.1 有判别力的校验是帆板级-母线级独立测点差额（两个不同物理测点，非构造量）：

Eshunt_diag = Σ (Isolar − Ibus) × Vbus × dt　（应 ≥ 0，S3R 分流+PCU 损耗的等效能量）

实测（观测窗口，kWh）：日照段帆板级发电 39.46 = 入母线发电 23.91 + 分流诊断 15.55；母线闭合 23.91 ≈ 13.14 + 12.62 − 1.86。两个方向均自洽，v2.0 的 −47.7% 母线残差待查项已随口径统一消解（原偏差源于把帆板级发电与母线级充电混算）。

6代码实现流程（energy_balancer.py）

class EnergyBalanceEvaluator
 load(wide)                 # 宽表输入 + 必需遥测列校验（缺列即报错）
 compute_power()             # P_solar(V_bus*I_bus)/P_load/P_excess/P_shunt_diag, 裁剪坏值
 classify_phase()            # 日照/地影(帆板级TMD009判据, 5样本滚动多数表决, 缺口切段)
 estimate_battery()          # 电压锚定SOC + 充放拆分(富余全充电, 全向量化)
 energy(phase)               # 分工况能量统计 + 帆板级/母线级独立差额
 run_all()                   # 汇总指标(稳健百分位) + 缺口诊断 + 健康度
 _health()                   # 加权健康度 + 分项 + coverage
